# align-mlflow

Import align-system Open World runs into MLflow for episode inspection and ADM comparison.

- [Import Align runs](INGESTION.md): ingest a run or study directory and open the results.
- [Manage a shared MLflow server](SERVER.md): install, configure, start, stop, upgrade, and back up.

Server setup includes [Open World results, session comparisons, and table controls](SESSION-UI.md) for everyone using that server.
